# Internship Project Tracker

A full-stack application for tracking internship projects, tasks, progress and weekly activities.

## Technology Stack

### Frontend

- React
- TypeScript
- Vite

### Backend

- Node.js
- Express
- TypeScript

### Development Tools

- Git
- ESLint
- Prettier

## Project Structure

- `frontend` — React frontend application
- `backend` — Express REST API

## Run the Backend

```bash
cd backend
npm install
npm run dev
